THE DATA PATH

Built to survive the messy parts
of real device fleets.

Intermittent networks, duplicates, replays, delayed readings, and tenant boundaries are normal operating conditions—not edge cases.

EDGEDevicecertificate + MQTT
→
CONTROLSecure ingressvalidate + acknowledge
→
STREAMOrdered eventspartition + replay
→
COLLECTProcessdedupe + normalize
→
OPERATEObserve & actquery + alarm + command
No silent loss

MQTT acknowledgements wait for a durable handoff. Failed records stay replayable or enter an explicit quarantine path.

No cross-tenant shortcuts

JWT scope, application context, PostgreSQL FORCE RLS, Kafka envelopes, Redis keys, and object paths all carry tenant identity.

No infrastructure magic

Plain Java domain boundaries sit behind replaceable MQTT, AWS IoT, storage, and analytics adapters.
